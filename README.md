## Sobre mí

Empecé a programar porque quería entender cómo funcionaban las cosas — no solo usarlas. Soy Ingeniero en Tecnología de Software por la UANL. Tras consolidar mi experiencia en el Frontend, he evolucionado al stack completo desarrollando y desplegando aplicaciones de inicio a fin.

Actualmente trabajo en **BAINUB** desarrollando interfaces para una plataforma B2B, y en paralelo diseño arquitecturas Full Stack utilizando el ecosistema de **React**, **Next.js** y **NestJS**.

- 🔭 Trabajando en: Plataformas financieras, E-commerce y optimización de despliegues (CI/CD).
- 🌱 Aprendiendo: Profundizando en arquitecturas en la nube y DevOps.
- 💡 Me mueve: Resolver problemas complejos y construir el producto de punta a punta, desde la base de datos hasta la UI.
